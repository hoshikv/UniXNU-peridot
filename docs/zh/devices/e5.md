# Rongyue E5（e5）

[Enceka/UniXNU-e5](https://github.com/Enceka/UniXNU-e5)

<div v-pre>

Rongyue E5 is a 5G senior bar phone \(feature-phone form factor\) with a removable battery, a 3.5-inch 320x480 ST7365P RGB565 panel, 2 GiB RAM, eMMC and a Unisoc UMS9621 \(Qogirn6Lite\) SoC with 2x Cortex-A76 plus 6x Cortex-A55. The record covers the BootROM-FDL-LK-BootShim-mu UEFI chain, XNU hand-off, framebuffer console, matrix keypad input, seed userland and the read-only eMMC block service.

## 固件与启动 {#firmware}

`device-verified`

### 硬件与依赖

- Vendor LK bootloader on the B slot, BootShim raw payload stub, mu-based UEFI firmware \(Silicium e5Pkg\), DarwinBoot EFI loader, payload FAT volume.

### 配置

- Boot chain: BootROM to FDL to LK to BootShim to UEFI \(4 MiB SILICIUM\_UEFI.fd\) to UEFI Shell \(startup.nsh\) to E5BootMenu.
- B slot boots the payload \(misc slot record: B priority 15, A Android fallback 14\); watchdog 300 s reboots failed boots.
- BootManagerLib launches the Shell through an E5 protocol \(GUID 9A48E983-AB52-4043-828C-5366DCDADB26\) resolved by LocateProtocol at TPL\_APPLICATION because DXE event queues never drain without timer interrupts.

### 操作步骤

- Build the firmware and payload with uefi/build-e5.sh, make-e5-payload.py and mk-boot-payload.py in the e5-xnu repository.
- Flash with tools/e5-uefi-cycle.sh flash \(writes boot\_b payload at LBA 8 plus the misc slot record\).
- Collect logs with tools/e5-uefi-cycle.sh collect \(Android pstore ramoops zones survive the reboot\).

### 开发经验

- UEFI timer interrupts are not delivered \(GIC delivery unconfirmed\), so the UniXNU menu counts down by polling and UEFI event notifications at or below the current TPL never dispatch.
- AON registers are clock-gated: the keypad and AON GPIO banks need set-mirror clock writes \(0x64901004, 0x64901018\) before any register access or the AXI bus wedges.
- The Shell must be started from PlatformBootManagerAfterConsole via a direct protocol call; a signalling event queues forever without timer ticks.

### 完成条件

- Firmware image builds, enters UniXNU, publishes the framebuffer and preserves the documented memory reservations.

### 当前范围

- GIC timer delivery in UEFI is still broken; countdown and Shell launch work around it with polling and direct protocol calls.

### 下一步

- Root-cause the missing UEFI timer interrupt through GIC distributor/CPU-interface state dumps.

`implemented`

### 配置

- UEFI: E5BootMenu installs a SimpleTextIn merge \(keypad first, chained serial ConIn\) on a vendor-path handle so the official UniXNU menu counts it.

### 操作步骤

- Watch the menu stop its countdown on a physical key press and navigate with arrows and select.

### 开发经验

- Payload FAT layout and boot image size are stable across rounds; the packed ramdisk size varies with the seed contents and shifts the staging window without breaking boot.

Root and boot payload are fully read back before reboot; the static-tool entry correction changes ls/cat signatures and requires rebuilding both numeric aliases and the cache. \#58 preserves every file except the kernel and matches the earlier kernel-only repacker byte-for-byte. \#59 replaces only the ADT memory property, validated over the entire sidecar. ## 诊断 {#diagnostics}

`implemented`

### 硬件与依赖

- Persistent pstore ramoops zones \(dmesg-ramoops-0..5, console-ramoops-0\) surviving the watchdog reboot into Android; e5-uplink fd 229 write mirror; E5FB rendered-text mirror; E5KINIT register read-back.

### 配置

- tools/e5-uefi-cycle.sh collect pulls the pstore zones into dumps/uefi-report-HHMMSS.txt after each flash cycle.
- The E5UL uplink lines are written from the seed shell through the kernel write hook with the E5UL prefix and reach the persistent ring.

### 操作步骤

- Flash, wait for the watchdog reboot into Android, then collect and grep the report for the E5 markers.

### 开发经验

- dmesg-ramoops-0 is a circular ring holding multiple boots; per-build markers \(INIT-START-vN\) are required to separate fresh output from residue.
- Kernel printf stays buffered without timer interrupts; the e5\_panic\_print tee path is what reliably reaches pstore.
- Raw wait status matters: \#55/\#56 print EXIT 0 for a child killed by SIGBUS, but EXITH is 0x0a. Cat startup traces locate the failure before C entry; \#57 aligns the C stack while preserving the original argc/argv pointer and all five commands exit 0. Read errors in cat now return exit 67 instead of silently reporting success.

### 完成条件

- Each claimed milestone has a reproducible command, a matching source or image revision and an accessible result.

### 当前范围

- Reports concatenate several boots; ring rotation can wipe early markers during log floods.

### 下一步

- Add a boot-counter prefix to every uplink tag so multi-boot residue is unambiguous.
